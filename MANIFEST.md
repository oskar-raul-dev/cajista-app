# Contenido del paquete

- `README.md`: instalación, configuración y uso multiplataforma.
- `export.py`: punto de entrada sin instalar el paquete.
- `pyproject.toml`: instalación opcional como comando `cajista`.
- `requirements.txt`: dependencias Python.
- `config.example.yaml`: configuración de referencia.
- `styles/default.css`: fuente visual personalizable.
- `cajista/`: implementación del conversor.
- `examples/example.md`: archivo de prueba.
- `legacy/`: scripts del primer conversor directo Markdown → DOCX, incluidos como referencia.
- `docs/pdf-docx-style-guide-v3.md`: guía visual original.
